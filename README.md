# Qualifix Service - Ottimizza Tagli

Repository ufficiale per l'hosting della landing page e della privacy policy dell'app **Ottimizza Tagli**.

## Contenuti del Repository
- `index.html`: Landing page ufficiale dell'applicazione.
- `privacy-policy.html`: Informativa sulla privacy richiesta da Google Play.
- `icona.png` / `favicon-180.png`: Icona dell'app, usata anche come favicon del sito.
- `screenshot-*.jpg`: Screenshot dell'app usati nella landing page.
- `.nojekyll`: File di configurazione per permettere la scansione dei file tecnici da parte di GitHub Pages.

## Link Utili
- [Scarica l'app su Google Play](https://play.google.com/store/apps/details?id=org.qualifix.service.ottimizza_tagli)
- [Sito Ufficiale](https://qualifixservice25-cloud.github.io/site-ottimizza_tagli/)
